util.utils.splitOnSeparator(s: str, separator: str = '.') → List[str]¶

Split a string on ‘.’ while respecting single- and double-quoted substrings.

Dots inside quoted regions are treated as literal characters and do not trigger a split. Quotes are stripped from the output tokens. A quoted region must span an entire token — a quote may only open at the start of a token and must close at the end of a token (immediately before a ‘.’ or end of string). Nested quotes of the opposite kind are allowed inside a quoted region.

Parameters:

  • s (str) – The input string to split.

  • separator (str)

Returns:

A list of substrings split on unquoted dots, with quotes removed.

Return type:

List[str]

Raises:

ValueError – If a quote appears mid-token, a quoted block is not properly terminated, or characters follow a closing quote before the next ‘.’ or end of string.

util.utils.openUrl(url: str) → bytes¶

Fetch the contents of a URL and return them as bytes for XML parsing.

Parses the given URL to detect its scheme. For file: URLs, the path is resolved to an absolute local path and read from the filesystem. All other schemes (e.g. http:, https:, ftp:) are fetched via urllib.request.urlopen().

The raw bytes are returned without decoding so that the XML parser can read the encoding declaration from the document itself and decode accordingly.

Parameters:

url (str) – The URL to fetch. May use any scheme supported by urllib.request, plus the file: protocol for local filesystem paths.

Returns:

Raw byte content of the resource, suitable for passing directly to an XML parser (e.g. xml.etree.ElementTree.fromstring() or lxml.etree.XMLParser).

Return type:

bytes

Raises:

  • ValueError – If url is an empty string.

  • FileNotFoundError – If a file: URL points to a path that does not exist.

  • urllib.error.URLError – If a remote URL cannot be reached.

Usage:

>>> xmlBytes = openUrl("https://example.com/feed.xml")
>>> import xml.etree.ElementTree as ET
>>> root = ET.fromstring(xmlBytes)

>>> xmlBytes = openUrl("file:///home/user/data.xml")
>>> root = ET.fromstring(xmlBytes)

Returns:

Return type:

Raises:

Usage:¶
class Shapes(ABC):
  @abstractmethod
  def area(self) -> float: ...

  @abstractmethod
  def perimeter(self) -> float: ...

circle = make_concrete(Shape, {
  "area":      lambda self: 3.14159 * 5 ** 2,
  "perimeter": lambda self: 2 * 3.14159 * 5,
})()

print(circle.area())       # 78.53975
print(circle.perimeter())  # 31.4159

util.utils.addToMenuBar(path: str, command: Callable | None = None, *, menu: Menu | None = None, accelerator: str | None = None, cascadePositions: dict[str, int] | None = None, separatorBefore: bool = False) → None¶

Add – or, if already present, replace – an entry in the app’s menu bar.

Pass exactly one of command or menu: command adds/replaces a plain command entry that invokes command when chosen; menu adds/replaces a cascade entry whose submenu is menu. The top-level menu bar itself is always the app’s own – resolved from tk._default_root’s configured menu (see getMenuBar()) – there’s no need to look it up and pass it in.

Parameters:

  • path – A "|"-separated path of cascade labels ending in the item’s own label, e.g. "File|Save view". All but the last segment name cascade submenus, created via getSubMenu() if they don’t already exist; the last segment is the item’s own label.

  • command – The callable to invoke when the item is chosen. Give this to add/replace a plain command item; mutually exclusive with menu.

  • menu – The submenu to show as a cascade. Give this to add/replace a cascade item; mutually exclusive with command.

  • accelerator – Optional accelerator string to display (e.g. “Cmd+S”).

  • cascadePositions – Where to put any cascade that has to be made, by label, eg: {"Edit": 1}; by default, at the end (as for addCheckToMenuBar()).

  • separatorBefore – Put a separator just above the item (unless it’s the first, or there’s one there already): it starts a group of items. removeFromMenuBar() removes the separator with the item.

Note:

Safe to call repeatedly with the same path – e.g. every time a window gains focus – since an existing entry with the same final label is reconfigured in place rather than duplicated (and, if it was previously the other kind of entry – command vs. cascade – it’s replaced in place, at the same position). So a window can add its items unconditionally whenever it gains focus.

util.utils.addCheckToMenuBar(path: str, variable: Variable, command: Callable | None = None, *, cascadePositions: dict[str, int] | None = None, separatorBefore: bool = False) → None¶

Add – or, if already present, replace – a check item in the app’s menu bar: it shows (and sets) the boolean variable, and calls command when chosen. Like addToMenuBar(), safe to call repeatedly with the same path (eg: each time a window gains focus, rebinding it to that window’s variable), and removed with removeFromMenuBar().

Parameters:

  • variable – The (boolean) variable the item shows and sets.

  • command – Called (after variable is set) when the item is chosen.

  • cascadePositions – Where to put any cascade that has to be made, by label, eg: {"View": 1} (just after “File”); by default, at the end.
