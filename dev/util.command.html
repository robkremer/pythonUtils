util.command module¶

Command objects serve to encapsulate actions so that they may be used in an undo/redo list, typically mapped to cmd-z and shift-cmd-Z keys (or ctl-z for non-Mac). They are also extended in the commandParser for use in command line applications using the argparse module.

This module defines the following command hierarchy:

Command abstract (requires do(), undo(), __str__())

  • do() defines execution of the command

  • undo() defines the undoing of the command

  • __str__()

class util.command.Command(name: str)¶

Bases: ABC

The top-level object for do/undo command objects. The minimal interface for these are are and __init__(name:str) constructor and the zero-parameter do() and undo() methods. The do() and undo() methods are specified as abstract; however, they have implementations that check to so they are not called back-to-back without the other between them and that do() is called before undo(), so you may want to call the relevant super() methods.

class util.command.LambdaCommand(name: str, do: Callable[[], NoReturn], undo: Callable[[], NoReturn], changesState=True)¶

Bases: Command

A alternative to implementing a new class overriding the do() and undo() methods. Instead this class’s constructor takes “do” and “undo” zero-parameter function references (typically lambda functions) and merely calls them in the do() and undo() methods. Typical instantiation:

incr = LambdaCommand(“inc”, lambda x=num: x.inc(), lambda x=num: x.dec())

class util.command.CommandWrapper(command: Command, name: str | None = None, setup: Callable | None = None, teardown: Callable | None = None, initSetup: Callable | None = None, initTeardown: Callable | None = None)¶

Bases: Command

A Command wrapper that always executes a setup function before a do() and undo() and a teardown function after (if the setup and teardown are supplied).

__init__(command: Command, name: str | None = None, setup: Callable | None = None, teardown: Callable | None = None, initSetup: Callable | None = None, initTeardown: Callable | None = None)¶
Parameters:

  • command – A Command to wrap.

  • name – [Optional] The name of the command; provided by Command if None.

  • setup – [Optional] A function to execute before a do() or undo() call on command

  • teardown – [Optional] A function to execute after a do() or undo() call on command

  • initSetup – [Optional] Like setup but only called on the first do() (before setup )

  • initTeardown – [Optional] Like teardown but only called on the first do() (after teardown )
