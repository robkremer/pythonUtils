util.rtValuesDialog module¶

RTValueDialog: a dialog of sliders for adjusting a running program’s parameters (each described by a Param) as it runs. (It uses matplotlib for its scales.)

Created on Nov 28, 2025

Code author: Rob Kremer <robkremer@me.com>

class util.rtValuesDialog.Param(default: T, min: T, max: T, help: str = '', log: bool = False)¶

Bases: Generic

Class used by the WorkerProcess objects to describe each parameter that can be modified at run time. min, max, help, and log are used primarily in conjuction with the RTValuesDialog dialog to implement an interface in the main process to allow a user to control these parameters in real time.
