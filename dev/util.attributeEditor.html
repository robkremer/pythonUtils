util.attributeEditor module¶

A Tk dialog for viewing and editing the attributes of an AttributedObject (see util.attribute): one row per attribute – its value, type and inheritance restrictions – with the values it inherits shown above it. editAttrsBox() returns the edits; applyEditAttrsBox() applies them.

Created on Mar 17, 2025

Code author: Rob Kremer <robkremer@me.com>

util.attributeEditor.GROUP_SEPARATOR = '/'¶

util.attributeEditor.treeOrder(keys: list[str]) → list[tuple[str, str, int]]¶

The order to show attributes in, grouped by the parts of their names (see GROUP_SEPARATOR), like a tree of folders: at each level, the names with no more separators first, then each group – its header, and then its own contents, likewise – all sorted (ignoring case). Eg: “a”, “b”, “a/a”, “a/b”, “a/a/a”, “a/a/b”, “b/a” are shown as:

a
b
a/      (a group)
  a/a
  a/b
  a/a/    (a group)
    a/a/a
    a/a/b
b/      (a group)
  b/a
Parameters:

keys (list[str]) – The attribute names.

Returns:

(kind, name, depth) for each line: kind is “key” (name is an attribute’s name) or “group” (name is the group’s path, eg: “a/a”).

Return type:

list[tuple[str, str, int]]

class util.attributeEditor.AttrEditor(parent, attrs: AttributedObject, title='Attribute Editor', disabled=False, displayValues: dict[str, Any] | None = None, hideColumns: Iterable[str] = (), listItemMakers: dict[str, Callable[[Misc], str | None] | dict[str, Callable[[Misc], str | None]]] | None = None)¶

Bases: Toplevel

Implements a graphical editor for an AttributedObject of the form:

<editor lines> …

[<Message line>]

[<Answer line>]

<Add New Attribute button>

<Cancel button> <Save button>

where <editor lines> look like this:

<stat>

<label>

<value editor>

<type>

<note>

<button> <button>…

<stat>

<label>

<value editor>

<type>

<note>

<button> <button>…

If any attribute’s name has a “/” in it, the lines are grouped by the parts of the names, like folders (see treeOrder()): each group has a header line with a triangle that collapses or expands it, and each attribute is labelled with just the last part of its name, indented under its group.

The <Message line> and <Answer iine> are only visiable when the setMessage() or ask() methods are called.

collapsedGroups: set[str] = {}¶
