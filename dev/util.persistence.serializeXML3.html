util.persistence.serializeXML3 module¶

The XML3 strategy: XML2’s compact objects, in a document with a head (see SerializationStrategy.tostring()):

<?xml version='1.0' encoding='utf-8'?>
<document>
  <head>
    <property key="format" value="XML3" />
    <property key="formatVersion" value="1.0" />
    ...
    <property key="type" value="sn.model.model.Model" />
    <property key="url" value="file:///Users/me/family.snm" />
    <property key="objects" type="int" value="137" />
    <property key="superDBs" type="list">
      <item value="sn:/sn" />
      <item value="sn:/baseRules" />
    </property>
    ...
  </head>
  <object type="sn.model.model.Model" id="1"> ... </object>
</document>

The head is plain: each property’s value is a string (type “str”, left out), an int, a float, a bool, a list of those (item tags), or a table of them (property tags). It can be read without reading the rest of the file (see readHead()). Documents written by the XML and XML2 strategies (an object at the top) are read too.

_tostringDocument(head: dict[str, str | int | float | bool | list | dict], body: Element, kwargs: dict[str, Any]) → str¶

Write a document (see tostring()). By default, as a table of two entries, head first: HEAD (a table of the head’s values) and BODY. A strategy may write it its own way (eg: two values one after another; see XML3SerializationStrategy), so long as _fromstringDocument() reads it, and the head comes first.
